# 大肥鱼 Live2D 桌宠 v1.0.1

Windows 桌面 Live2D 桌宠：无边框透明窗口、跟随鼠标视线、点击 / 抚摸 / 捏脸互动、待机小动作，
可接入 DeepSeek Harness（DSH）——让 AI 一边干活一边用气泡和动作「说话」。

## 本次更新（v1.0.0 → v1.0.1）

- **首次运行引导**：没放模型时不再「双击一下没了」，而是开一个窗口说明怎么放——可直接选 `.model3.json`、打开 `model` 文件夹、看日志
- **启动日志**：写到 `%APPDATA%\live2d-stage\logs\main.log`，打不开时有据可查
- **贴图压缩 `贴图压缩.cmd`**：把 4096/8192 贴图缩到最长边 2048。实测贴图内存 592MB → 64MB，整个程序 2.0GB → 0.6GB
- **动作编辑器重写**：实时调参、试播、**复制 / 粘贴关键帧**（Ctrl+C / Ctrl+V）、预览大小与位置可拖拽缩放；
  内置 5 个姿势 + 10 个待机动作全部列在左栏，可以直接改成自己的版本
- **气泡显示表情包**：AI 回复里带 `[表情: 描述]` 时，气泡上图下字
- **干活过程可见**：写文件 / 搜代码 / 跑命令会显示成「写文件 · editor.js」这样的具体动作
- **会话反馈**：回合结束把最终回复说进气泡，**60 字以内原文直出**，更长的才压成一句
- **开场报到提速**：竖食指从 4 秒过渡改为 320ms，说完自动放手，不再和台词叠在一起
- **修 `--model`**：之前参数解析了但没生效，现在按 参数 → 设置 → `model\` → 环境变量 的顺序生效

## ⚠️ 模型需要单独下载（安装包不含模型）

**本 Release 的安装包不含「大肥鱼」模型**，因为模型版权归原作者、作者禁止二次发布：

1. 自行向原作者获取模型：Bilibili UP 主 **神宫凉子**，视频 [BV1KmxY66EZ3](https://www.bilibili.com/video/BV1KmxY66EZ3)
   （`大肥鱼.model3.json` + `moc3` / 贴图 / 动作 / 物理）；
2. 解压本安装包，在 `大肥鱼Live2d桌宠.exe` 旁边新建 **`model`** 文件夹，把模型整个放进去；
3. 双击 `大肥鱼Live2d桌宠.exe` 即可 —— 自动读 `model\`，不用配路径。

也支持任意 Cubism 5 导出的 `.model3.json`，但互动热区是按大肥鱼模型调校的，其他模型需要自己调。

## 快速开始

1. 解压到一个固定目录（路径含中文没问题）；
2. 在 exe 旁边建 `model\` 文件夹，把模型目录整个拷进去（推荐，零配置）；模型不方便挪的，用 `挂载模型.cmd` 或 `--model` 指定路径；
3. 之后每次启动直接用；换模型：右键角色 → 设置 →「模型」→「更换 Live2D 模型」，或直接换 `model\` 里的内容。

> 配置里只记相对路径（`model/大肥鱼.model3.json`），整个文件夹换位置、拷到别的机器都不用改配置。

### 内存占用大？跑一下 `贴图压缩.cmd`

模型的大贴图解压后能到 600MB。双击包内 `贴图压缩.cmd`，会把贴图按最长边缩到 2048 并自动切过去，
桌宠整体内存从约 2.0GB 降到 0.6GB（画质在 520×760 的窗口上看不出差别）。

### 启动参数（可选，给快捷方式 / 自动化用）

```
大肥鱼Live2d桌宠.exe --model "D:\模型\大肥鱼.model3.json"
```

- 模型查找顺序：`--model` → 设置里的路径 → exe 旁 `model\` → 环境变量 `STAGE_MODEL`；
- 环境变量 `STAGE_HOME=<目录>`：把设置 / 配置放到指定目录（便携用法）；
- 环境变量 `STAGE_MODEL=<路径>`：同 `--model`，优先级最低。

### 脚本化挂载（不弹窗、可复现）

```
挂载模型.cmd "D:\模型\大肥鱼.model3.json"
```

它会校验 moc3 / 贴图 / 动作文件是否齐全，并把路径写进设置文件（使用 `STAGE_HOME` 可指定别处）。

## 操作

- **左键拖角色**：搬窗口（拖动时有拖拽物理，头发 / 裙子会甩）
- **右键角色 / 空白处**：工具条（设置 / 退出）
- **点头部**：摸头；**点额头**：常态 / 爱心眼 / 眼镜 三态切换
- **按住脸拖动**：捏脸（跟随鼠标力度）
- **摸脚 / 摸腰**：痒痒的（耳朵扑扇 + 身体乱晃）
- **点手**：竖食指 / 放下
- 设置里可调：角色大小、上下留白、窗口边框拖拽缩放、跟随强度、转头幅度、待机频率、
  全部表情与官方姿势、体型拉条、拖拽物理开关、开机自启、气泡开关等
- 快捷键：`Ctrl+Alt+L` 切换鼠标穿透，`Ctrl+Alt+Q` 退出

## 动作编辑器

设置窗口 →「动作编辑器」打开，或由舞台的设置面板进入：

- 左栏：动作列表（内置 5 个姿势 + 10 个待机动作 + 你建的），可改名、改时长、写配字（一行一句）
- 中间：真渲染预览，拖动移动角色、滚轮缩放、双击复位；时间轴上可加/删关键帧、**复制帧 / 粘贴帧**、播放
- 右栏：参数搜索（支持中文别名，搜「前倾」「换手」「抚胸」都能命中）+ 滑块，拖动即在当前时间落关键帧
- 自动保存到 `actions.json`，也有「保存」按钮手动写盘；存档位置 `%APPDATA%\live2d-stage\actions.json`

## DSH 对接（可选）

`dsh-live2d-bridge.zip` 是配套的 DSH 插件，作用：

1. 把 DSH 会话状态投到角色上（思考中 / 干活中 / 等你确认 / 成功 / 出错），干活时带具体动作：
   「写文件 · editor.js」「搜代码 · agent-link」「跑命令 · npm run pack」；
2. 给 agent 注册 `live2d` / `live2d_status` / `live2d_actions` 三个工具：
   AI 能主动说话、换表情、做动作，也能直接读写动作存档（和编辑器同一份 `actions.json`）；
3. 回合结束把最终回复说进气泡（60 字以内原文直出），带 `[表情: 描述]` 时气泡显示图片；
4. 新会话自动报到：「连接成功啦～」+ 竖食指。

安装（放到 DSH 的 profile 里）：

```bash
mkdir -p ~/.dsh/plugins && unzip dsh-live2d-bridge.zip -d ~/.dsh/plugins
```

然后在 `~/.dsh/profiles/<你的 profile>/package.json` 的 `dependencies` 里加
`"dsh-live2d-bridge": "link:<解压出来的目录>"`，并在 `bundles` 数组里加上 `"dsh-live2d-bridge"`，重启 DSH。

> 桌宠启动后会把自己的「端口 + token」写到 `~/.dsh/live2d/endpoint.json`，
> 插件通过它控制舞台——不需要额外开端口或配置。
