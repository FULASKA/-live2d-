# 大肥鱼 Live2D 桌宠 v1.0.0

一个 Windows 桌面 Live2D 桌宠：无边框透明窗口、跟随鼠标视线、点击/抚摸互动、待机动作，
并且可以接入 DeepSeek Harness（DSH）——让 AI 一边干活一边用气泡和动作「说话」。

## 两个包

| 包 | 内容 | 用途 |
| --- | --- | --- |
| `大肥鱼Live2d桌宠-完整版-win32-x64.zip` | 程序 + **大肥鱼模型** | 自用 / 已经获得模型授权的人 |
| `大肥鱼Live2d桌宠-发布版-win32-x64.zip` | 只有程序，**不含模型** | 公开分发 |

> **模型版权**：大肥鱼模型版权归原作者所有，**禁止二次发布/再次分发**。
> 所以公开下载请用「发布版」；模型请自行从原作者处获取。
> 完整版仅供本机使用，不要上传到任何公开渠道。

## 快速开始（发布版）

1. 解压到一个固定目录（路径尽量不含空格也可以，含中文没问题）；
2. 双击 `大肥鱼Live2d桌宠.exe`；
3. 第一次启动会弹窗让你选择模型：选你自己那份 `大肥鱼.model3.json`（它会记住路径）；
4. 之后每次启动直接用即可。

> 选错模型了？右键角色 → 设置 → 「模型」→「更换 Live2D 模型」。

### 启动参数（可选，给快捷方式 / 自动化用）

```
大肥鱼Live2d桌宠.exe --model "D:\模型\大肥鱼.model3.json"
```

- `--model <路径>`：启动时直接指定模型，跳过选择框；
- 环境变量 `STAGE_HOME=<目录>`：把设置/配置放到指定目录（便携用法）；
- 环境变量 `STAGE_MODEL=<路径>`：同 `--model`，优先级低于命令行参数。

首次启动如果找不到模型，会弹选择框；取消则提示缺少模型并退出。

## 操作

- **左键拖角色**：搬窗口（拖动时有拖拽物理，头发/裙子会甩）
- **右键角色 / 空白处**：工具条（设置 / 退出）
- **点头部**：摸头；**点额头**：常态 / 爱心眼 / 眼镜 三态切换
- **按住脸拖动**：捏脸（跟随鼠标力度）
- **摸脚 / 摸腰**：痒痒的（耳朵扑扇 + 身体乱晃）
- **点手**：竖食指 / 放下
- 设置里可调：角色大小、上下留白、窗口边框拖拽缩放、跟随强度、待机频率、
  全部表情与官方姿势、体型拉条、拖拽物理开关、开机自启、气泡开关等
- 快捷键：`Ctrl+Alt+L` 切换鼠标穿透，`Ctrl+Alt+Q` 退出

## DSH 对接（可选）

`dsh-live2d-bridge.zip` 是配套的 DSH 插件，作用：

1. 把 DSH 会话状态写成本地文件，桌宠读它显示「思考中 / 干活中 / 等你确认 / 成功 / 出错」；
2. 给 agent 注册 `live2d` / `live2d_status` 两个工具，让 AI 主动控制角色说话、换表情、做动作；
3. 新会话开始时自动报到：「连接成功啦～」+ 竖食指。

安装（放到 DSH 的 profile 里）：

```bash
# 解压到插件目录
mkdir -p ~/.dsh/plugins && unzip dsh-live2d-bridge.zip -d ~/.dsh/plugins
```

然后在 `~/.dsh/profiles/<你的 profile>/package.json` 的 `dependencies` 里加：

```json
"dsh-live2d-bridge": "link:D:/path/to/dsh-live2d-bridge"
```

并在 `bundles` 数组里加上 `"dsh-live2d-bridge"`，重启 DSH 即可。

> 桌宠启动后会把自己的 `端口 + token` 写到 `~/.dsh/live2d/endpoint.json`，
> 插件通过它控制舞台——不需要额外开端口或配置。

## 系统要求

- Windows 10 / 11 x64
- 无需安装运行时（便携版，解压即用）
- 模型：Cubism 5 导出的 `.model3.json`（本程序按大肥鱼模型调校，其他模型也能加载，但互动热区需要自己调）
